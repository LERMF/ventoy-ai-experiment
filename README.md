# Ventoy AI Experiment

Experimento científico para preparar pendrive bootável com Ventoy + LLM embarcado para diagnóstico e decisões de boot autônomas.

## Estrutura

- `configs/`: Configurações Ventoy, USBGuard, TPM
- `scripts/`: Automação de instalação e monitoramento
- `llm/`: Modelo GGUF e prompts especializados
- `data/`: Logs, benchmarks e atestações
- `sbom/`: Bill of Materials e checksums
- `docs/`: Relatórios diários e pesquisa

## Status

- Início: 2025-09-30
- Objetivo: Boot seguro + IA embarcada em USB
